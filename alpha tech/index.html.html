Perguntas frequentes

PCM significa Planejamento e Controle da Manutenção. O Alpha Tech foi pensado para apoiar o planejamento, organização, execução e acompanhamento das atividades de manutenção.
O plano registra What, Why, Where, When, Who, How e How Much — respectivamente o que, por quê, onde, quando, quem, como e quanto custa.
A pontuação é Gravidade × Urgência × Tendência. Cada fator recebe uma nota de 1 a 5. Quanto maior o resultado, maior a prioridade operacional sugerida pelo método.
Nesta versão demonstrativa, os dados ficam no armazenamento local do navegador. O botão de backup permite exportar um arquivo JSON para restauração.
A câmera depende das permissões do navegador. O leitor utiliza uma biblioteca QR carregada no navegador para reconhecer o código e localizar o equipamento cadastrado.
